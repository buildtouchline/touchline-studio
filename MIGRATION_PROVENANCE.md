# Snapshot provenance

This repository was initially created privately from `buildtouchline/touchline` commit
`fc977d8ae9b9d315689199795325f2fe71970fa8` on
`fix/panorama-studio-remediation`. The archived repository retains the
historical commits, PRs and individual author/committer metadata. The fresh
initial commit here identifies the person preparing the snapshot, not the
author of every source file.

Team Vikzar and the contributors authorised migration and public publication
for Meta hackathon evaluation. The archived repository retains contributor
attribution; applicable third-party notices and attribution in source and technical
documents remain in place. Public visibility does not grant unrestricted reuse.

The migration copied only exact tracked source-commit paths selected by an
explicit allowlist: `src/touchline/`, `tests/`, `tools/`, `docs/`, `examples/`,
`notebooks/`, `.gitignore`, `pyproject.toml` and `HANDOVER.md`. The source
README was replaced with a repository-specific README that retains Team
Vikzar's copyright and use restriction. The old `AGENTS.md`, `Skills.md`,
`skills/` and `.github/CODEOWNERS` were excluded. No Git history, branches,
pull requests, datasets, footage, checkpoints, model weights, credentials,
local environments, caches or generated runs were imported.

The original worker is experimental. Temporary tracks are not confirmed
roster identities; a completed mock test is not a completed paid GPU trial.
